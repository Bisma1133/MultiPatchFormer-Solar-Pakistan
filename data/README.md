# Data

Place the combined Solcast files here:

* `Solcast_4cities_2020_2024.csv` (main experiments)
* `Solcast_4cities_2017_2024.csv` (longer-training experiment)

They are archived on Zenodo (DOI 10.5281/zenodo.20691120). See the main README for the Solcast request parameters, the site coordinates and how to rebuild the files with `scripts/make_dataset.py`.
